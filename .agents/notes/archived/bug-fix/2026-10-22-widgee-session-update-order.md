# Agent Note: Widgee 会话更新时间排序与后置历史列表

Status: implemented
Archived: 2026-11-05

## 问题

把缓存访问时间用于会话排序会使只读浏览置顶。只含创建和删除的目录日志无法同步其他客户端对已有会话的更新；HTTP 历史和 SSE 又可能与目录响应交错，缺少版本比较会让旧摘要覆盖新状态。

## 决策

列表按服务端 updatedAt、createdAt、id 降序排列；缺少 updatedAt 时回退到 createdAt，再回退到 0。浏览只更新缓存 LRU 的 accessed。发送尚未被接受时保持原排序；服务端确认的正式更新写入缓存后重排。

ChatStore 在接收用户消息、保存正式助手消息、产物、标题或 turn 终态的批次中原子更新业务时间、持久化事件和追加一次目录 update。时间不倒退。内部 pi 条目、attempt、临时文本、心跳和幂等重放不产生业务更新。共用的 webclip Store 保留原有行为。

摘要的 summaryVersion 使用会话事件高水位。同一业务批次的公开事件携带相同完整 session 摘要；HTTP 历史及目录返回读取时的摘要。客户端只合并不低于当前摘要版本的状态。目录版本、摘要版本和消息 cursor 各自推进；即使已收到终态摘要，也必须读取尚未缓存的早期消息。删除标记优先，迟到 update 不能恢复会话。

服务端扩展目录表 operation 约束时保留日志版本、epoch 和删除记录。客户端把可选 summaryVersion 存在已有 JSON 摘要内，不需要清空数据库或迁移用户数据；缺少版本的旧摘要按 0 比较。线上字段和升级顺序由 [Widgee 协议](../../../../docs/widgee-protocol.md)维护。

历史列表在完整聊天 NavigationStack 后方，菜单只显示图标。点击菜单或在聊天区域明显右滑时，聊天页右移，保留右侧页面边缘与阴影；向左滑动列表或页面露出区域、选择会话、点击菜单或页面露出区域收起。会话删除使用长按菜单，避免占用左滑关闭手势。手势开始时按水平位移超过垂直位移的 1.5 倍锁定横向，滚动容器等待方向判定；横滑独占手势，纵滑交给滚动容器。横向累计位移达到 60pt 时，在结束手势后打开或关闭。列表和聊天宿主保持稳定身份，打开抽屉不重建模型、滚动状态或预览。关闭到展开的状态变化触发一次系统轻量 impact；收起和刷新不触发。减少动态效果时取消位移动画，无障碍标签保留操作名称。

本记录部分调整 [SQLite 会话缓存](../feature/2026-10-21-widgee-sqlite-session-cache.md)的目录更新策略，保留其事务、删除标记、身份隔离、LRU 和离线读缓存决策；扩展 [底部导航与资料库](../feature/2026-10-19-widgee-tabbed-chat-library-ux.md)的历史抽屉。两篇记录仍拥有独立理由，保持活跃，无归档或删除。

## 曾考虑的替代方案

**只修改 SQL 排序字段。** 能阻止浏览置顶，但既有 SSE 不更新摘要时间，目录也不传已有会话更新，无法保证继续聊天和其他客户端更新后的排序。

**本地点击发送时写当前时间。** 会把未确认或已拒绝的发送置顶，并受客户端时钟影响。业务时间由服务端确认，离线展示最近已知状态。

**每次打开抽屉全量拉取摘要。** 丢失增量收益，按更新时间排列的 offset 分页还会在并发更新时漏项。追加日志提供稳定同步位置，不以缺项推断删除。

**只调整覆盖式抽屉的颜色和宽度。** 无法形成聊天页在前、历史列表在后的层级，因此移动完整聊天页面。

## 验证

23 项宿主缓存/同步测试通过，覆盖重启、浏览排序、等待 POST 确认后经真实 ChatModel SSE 消费置顶、未打开会话的目录更新、同更新时间的版本比较、较旧目录/历史/SSE 摘要、独立消息游标，以及打开 session_not_found 时关闭和删除。测试使用固定时间值、独立数据库/URLSession 与响应屏障。

55 项后端聊天、目录和 Store 测试通过，覆盖业务更新、只读与内部事件不更新、时间倒退、事务回滚、旧目录表迁移、日志版本与 epoch 保留、删除和幂等。六组负例分别移除事务、删除保护、目录版本保护、已提交消息发布、业务时间排序和摘要版本保护，均被行为断言拒绝。

类型检查、SwiftLint strict、verify-ios、文档和 Agent Notes 门禁通过。真机 UI 验证缓存冷启动、挂起网络时读缓存、编辑草稿、带纵向偏移的右滑展开、列表及页面边缘左滑关闭、菜单展开与收起、前后层级几何、阅读锚点保持、远端删除及删除后冷启动。目录分页与删除 smoke 通过。最终真机结果保存在 ios/.build/ChatCache-1792634430290.xcresult；附件确认菜单仅显示图标、顶部安全区与聊天渐变衔接一致。触觉调用条件有实现，实际震感、VoiceOver 人工走查、深色和最大辅助字号未完成本轮人工验证。

## 后果

目录写入量随正式业务批次增长；不对 token 和内部条目逐条记账。公开事件附带摘要增加少量传输与缓存体积，换取实时确认后的排序及可比较的完整状态。新旧客户端与服务端需要按协议协调发布；代码和本地验证不等于生产服务已部署。

离线期间只能按最近已知更新时间排列，不能即时感知远端新消息。旧历史的更新时间不通过本机浏览时间补写。顶部安全区与聊天页共用渐变背景，展开时后层采用系统背景；系统设置和硬件决定触觉是否可感知。
