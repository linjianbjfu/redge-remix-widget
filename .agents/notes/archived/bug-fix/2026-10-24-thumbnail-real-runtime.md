# Agent Note: 缩略图生产复用真实运行环境

Status: implemented
Archived: 2026-11-05

## 问题

人工生产页需要检查可用于广场的真实 Widget 画面。以 BridgeRegistry.stubs 为基础逐项覆盖能力，会让未覆盖的 API 返回成功的样例值，与普通运行页不同。「晴雨之间」调用 image.draw 绘制天空背景时得到 minis-image://sample，该地址在图片解析后被清空，PNG 校验报 invalidImage。

[双语生产决策](../../implemented/feature/2026-10-23-shared-widget-localization.md#ios-缩略图生产-view)最初复用受限预览，随后逐项开放步数、天气和定位。合法脚本持续暴露能力缺口，没有独立要求绘图必须模拟的决策。Beads 为 `webclip_widget-u4x`。

## 决策

人工缩略图生产是使用临时数据的真实运行。配置界面复用 WidgeeBridges.makeRegistry；无配置界面的 Widget 复用 makeWidgetRegistry 和 WidgetRunner，遵循普通 Widget 的 API 范围及系统权限。生产入口不维护额外的健康、定位白名单，不返回模拟成功。聊天离线校验、编辑器与资料库 fallback 的模拟环境不属于此决策。

生产只覆盖必要的显示参数：device.info 先取真实设备信息，再替换目标 language、locale 和浅色字段；其他 device 操作委托真实模块。WeatherModule 使用稳定 condition 标识，由目标语言源码映射文案，避免英文脚本收到系统中文天气描述。SwiftUI 使用目标 locale、浅色、标准字号及投稿尺寸，不更改手机语言与外观。

每个任务语言拥有随机 appID、临时目录和 ImageStore。storage、files、下载文件及脚本 Keychain 与已采用 Widget 和其他语言隔离；管理员令牌仍由独立管理客户端和 Keychain 项持有，不提供给脚本。显式复制上一语言配置使用独立快照，复用 WidgetDataCopy 重定位文件引用、持久化内存图片并复制临时脚本凭据，下一语言不依赖已释放的资源；跨 Widget 不复制。

聊天真实预览和生产共用 WidgetPreviewImages，将运行时图片及本地文件转换为内联 PNG，然后解析远程图片并编码截图。缺失、损坏或无法解析的图片继续拒绝。脚本 fetch 使用真实 FetchModule，PreviewNetwork 只负责截图资源下载；不能把它的请求与字节限额宣称为全部脚本请求的限制。

预览来源标识允许本次投影的缓存写入，其他输入、运行状态及存储、文件、凭据写入使预览失效。提交发送用户确认的同一份 PNG；配置快照在上传前完成，复制失败不会发生在上传成功之后。语言切换与结束先取消并等待原生调用、预览和图片下载退出，再清理临时资源、脚本凭据及该 appID 的通知。调用结束后再次清理订阅，防止取消之后才完成的注册留下后台活动。WidgetRunner 的截止时间与取消会停止 JavaScript 运行时，使未决 Promise 能退出。

此决策部分替代双语生产笔记的受限桥接和单文件配置复制；语言产物、领取租约、人工确认、原图复用及审核发布仍由原笔记拥有，保留并互相链接。[聊天配置草稿与真实预览](../../proposed/feature/2026-10-20-widgee-chat-saved-configuration-preview.md)继续拥有聊天草稿及采用复制，其未完成验收不合并到本记录。

## 曾考虑的替代方案

**只补真实 ImageModule 和图片内联。** 能解决天空背景，但其余模块仍可能返回样例，继续维护生产与普通运行之间的能力差异。

**仅替换注册表。** 改动少，但不能解决图片 URI、目标语言、临时 Keychain 清理和跨语言文件引用，也不能保证取消后没有迟到写入。

**另建生产专用真实只读白名单。** 能缩小系统写入范围，但继续维护不同的能力矩阵。人工配置和人工提交入口复用普通运行语义；若引入无人值守执行任意投稿，必须重新明确权限边界，不能把存储隔离当作安全沙箱。

## 后果

真实实现消除模拟能力缺口，同时保留真实服务的网络错误、系统授权、数据变化和副作用。独立存储不回滚日历、健康、相册或远端写入，也不承诺任意文件访问仅限临时目录。真实权限不等于必然获准，失败不能替换为样例成功。生产不自动引入作者或操作员已有 Widget 的配置；配置与凭据不附加到投稿，但脚本可以将值发往其服务或显示在最终 PNG 中。

固定显示参数不保证任意外部 API 的返回文案语言，也不保证两次截图的数据相同。PNG 校验不能判断业务错误画面是否适合发布，仍需操作员确认。后台生产、跨重启草稿恢复与云端部署不在本改动范围。

## 验证

ThumbnailRealRuntimeTests 的 11 个用例覆盖双语真实绘图、配置型与 widget-only 入口、实际「晴雨之间」源码的未配置及昼夜画面、真实 HTTP 图片与下载、独立文件和凭据复制、无效图片、权限拒绝、取消、截止时间、迟到写入与订阅清理。旧注册方式下真实绘图回归报 invalidImage；修复后生成有效 PNG。既有测试继续覆盖缓存来源、并发配置失效、上传字节及租约约束。可复跑命令由 [iOS README](../../../../ios/README.md) 和[开发指南](../../../../docs/development.md#ios-缩略图生产与审核)拥有。

真机通过真实天气、城市查询、已授权步数、地图快照及双语天空绘图验收；步数检查要求可读非零样本，没有向系统写入测试健康记录。晴雨之间的昼夜回归使用受控缓存，天气和地图另走真实服务。其他系统模块复用共享实现，未声称逐项真机验证成功。手机账号、服务地址与语言设置经完整偏好文件比较保持不变。

真实模型生成、翻译、原生补图、审核、双语公开下载、采用与删除，以及隔离配置 fixture 的双语输入、复制和上传均有 E2E 验证。UI 操作等待控件完整进入导航栏与底部栏之间，并在预览布局变化后滚动到提交按钮再检查状态，避免遮挡点击和离屏查询。验收证据保存在本机 `.playwright-mcp/thumbnail-real-u4x/` 及相应 `gallery-native-*` 目录；未向日常广场投稿写入测试数据。
