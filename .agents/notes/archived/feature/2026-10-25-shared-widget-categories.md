# Agent Note: Shared Widget 分类与审核保存

Status: implemented
Archived: 2026-11-05

## 问题

Shared Widget 需要统一分类及多语言名称，管理员需要在发布前独立保存分类。当前尚未发布的本地五份已通过作品需要重新分类审核，同时保留源码、双语缩略图和已采用的本地副本。

## 决策

每份投稿只有一个分类，父记录保存可空 category_id；空值表示未分类，不自动归入工具，不参与投稿摘要或身份。服务端维护日历、天气、工具、股票、健身的固定目录，以 calendar、weather、tools、stocks、fitness 为稳定 ID，返回简体中文或英文名称。服务端统一拥有名称，避免各客户端复制目录；增加分类不要求旧 App 同步升级。

客户端与 Admin 获取同一个本地化目录。已发布内容及 Admin 详情返回 category，非公开同步标记不暴露分类。iOS 解码和缓存分类，兼容缺少字段的旧数据，允许未来分类 ID；[分类浏览](2026-10-25-gallery-category-sections.md)拥有首页分组、分类列表与尺寸角标，直接使用已同步条目。字段和路由由[协议](../../../../docs/widgee-protocol.md#widget-广场)维护。

Admin 仅在 pending 开放分类选择。“保存分类”只保存分类并保持待审核，保留尚未提交的标题与简介；批准可以同时提交分类和文案。批准及自动发布要求有效分类，拒绝允许未分类。分类保存携带 expectedUpdateAt；同值重试不再次推进版本，不同值的旧版本请求返回冲突。审核将分类、文案和状态原子写入，并核对版本，避免覆盖另一管理员已保存的分类。

备份 v6 保存分类，读取 v1–v5 时补空值。同 ID 导入保留目标当前分类与状态。无分类的历史批准取消自动批准来源，双语产物齐全则待审核，未齐则先完成生产；有效分类保留历史审核语义。校验源备份的状态与公开引用后，才对转待审核的记录清空公开引用，避免接受原本非法的备份。原产物身份不变。

### 本地重审与缓存

用户确认产品尚未发布，本地五份作品的此次退回不推进 update_at，不建立面向已发布客户端的增量兼容流程。轻盈步数、微软股票、农历日历、彩色天气、晴雨之间已按完整 ID 从 approved 转为 pending，清空审核信息和历史批准标记，不自动分类。schema 迁移只增加字段，不重置其他环境的业务状态。

退回清空语言记录的公开引用，以满足待审核记录不可声明已发布的持久化约束；私有与公开对象字节全部保留，未重新生产。旧公开 URL 仍可能读取资源，此操作不提供资源撤回保证。其他未清理缓存的测试客户端需要重建广场缓存，普通增量刷新不能保证移除此批旧卡片。正常业务写入仍递增 update_at。

手机已安装最新 App，广场缓存已清除。偏好核对发现连接设置重置，已从操作前备份恢复并重启，核对全部原偏好保留；已采用组件资料库逐字节一致。这里核对的是设备文件及启动结果，没有宣称完成真机广场页面目视验收。未执行云端迁移、数据修改或部署。

## 曾考虑的替代方案

**只存中文分类文字。** 语言切换会改变匹配身份，采用稳定 ID 和本地化名称。

**只在 App 内维护翻译。** 其他客户端需要复制目录，新增分类要求同步升级；服务端统一返回名称。

**选择分类后立即批准。** 不能独立整理分类，容易误发布；保存与批准分开。

**schema 迁移重置全部已通过记录。** 会将本地整理扩散到其他环境，也无法先核对具体作品；采用带快照和状态检查的一次性本地操作。

**此次退回推进同步版本。** 适用于不能统一重建缓存的已发布客户端。用户选择清理测试客户端缓存，当前一次性操作保留原版本。

## 验证

Gallery 42 项、备份 16 项、翻译与 CLI 27 项、iOS Gallery 18 项测试通过，覆盖双语分类、非法分类、未分类批准拒绝、旧缓存兼容、保存幂等、并发分类与审核、失败回滚、备份兼容及本地副本保留。完整 Admin E2E 覆盖保存后刷新、草稿与导航保护、冲突、审核发布和双语客户端响应；广场 HTTP E2E 的 8 个生产分享场景通过。TypeScript、Admin 构建、iOS 静态约束和本地化门禁通过。

本地 Admin 实际核对已通过 0、待审核 5，晴雨之间详情具有五分类下拉框和独立保存按钮，没有替用户分类或批准。一次性操作验证目标状态、update_at 保持不变，45 份私有／公开对象摘要不变；隔离 SQLite 检查目标选择、冲突和重跑保护。手机安装、启动、缓存与偏好／资料库比较结果保存在忽略目录 .playwright-mcp/gallery-categories-q8y/。Admin E2E 桌面和窄屏截图由隔离服务生成。

## 后果

分类在发布前完成，客户端共享稳定身份与本地化名称。固定目录不提供管理后台、多标签或自动分类；一个作品只有一个分类，中英文以外的请求回退英文。扩展时可沿用 ID 和语言目录，不需要改变源码或图片路径。

无分类历史内容需要人工审核，旧备份不能绕过分类要求。分类与审核冲突需刷新后处理。保留公开资源不提供撤回时效保证；本地重审期间，这五份作品不会出现在重建缓存后的广场中，重新批准后按正常同步重新出现。
