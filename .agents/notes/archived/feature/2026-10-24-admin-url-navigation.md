# Agent Note: Admin URL 导航与刷新恢复

Status: implemented
Archived: 2026-11-05

## 问题

Admin 的状态筛选、已加载列表、Widget 详情与查看语言原本只保存在页面内存，登录恢复固定回到已通过。管理员需要刷新继续查看当前作品，以及复制链接打开同一浏览视图。

## 决策

Admin 保留单一 `/admin/` 入口及列表上的详情弹窗，使用查询参数表达浏览位置。`admin/src/navigation.ts` 拥有参数解析、规范化及原生 History API 协调，`admin/src/app.ts` 按路由加载和呈现。没有新增路由依赖或服务端业务接口。URL 参数及用户操作由 [Admin README](../../../../admin/README.md) 维护。

URL 是筛选、详情身份、版本、源码展开和列表批数的来源；登录恢复后应用该位置。详情直接按 ID 独立读取，不依赖列表先找到作品，列表失败也不妨碍查看详情。服务端当前状态优先于旧链接中的状态；不存在或已删除的作品保留定位地址并显示错误，语言缺失时明确提示并规范化到可用版本。非法投稿 ID 不进入 API 路径，重复参数取首值后规范化，未知参数与冗余默认值不保留。

状态切换和打开作品新增历史条目；版本、源码及批数替换当前条目，避免后退穿过大量局部操作。历史元数据只保存条目序号、来源列表、滚动位置及卡片身份，不保存凭据和表单。关闭来自列表的详情返回原条目；外部直达详情关闭时替换为同一筛选列表，避免退出 Admin。批准、拒绝和删除成功后替换为原筛选列表，重试发布保留当前详情版本。

浏览器 popstate 在 URL 改变后触发，因此导航协调器先返回已接受条目，再检查未保存修改或正在提交的操作。确认后重访目标条目；取消不新增历史、不丢弃编辑。异步读取只向当前视图所属历史条目写坐标，不能覆盖临时经过的目标条目。成功写操作等待正在处理的导航结束后关闭详情，避免审核成功恰逢后退时遗留旧表单。相同 Widget 内查看语言或源码保留编辑内容；整页刷新和离开使用原生未保存提示。

累加列表按批数重新遍历已有游标接口，每批 20 条。恢复有进度、停止和失败重试，到末尾校正实际批数；详情不必等完整列表恢复。切换路由取消旧读取，图片与源码继续遵守原有按需加载、并发限制和资源释放规则。同标签页返回列表尽量恢复滚动及焦点，恢复读取被新导航取代时不再移动滚动位置。

### 决策归属

本记录扩展 [Admin 浏览与编辑](2026-10-22-admin-gallery-browsing-editing.md)的导航及未保存保护，[Admin 登录](2026-10-23-admin-session-login.md)继续拥有凭据与会话机制。[双语生产](../../implemented/feature/2026-10-23-shared-widget-localization.md)拥有语言产物和审核前提；[删除](2026-10-22-admin-gallery-deletion.md)拥有删除语义。四篇均有独立决策价值，保持活跃，无完全取代、归档或删除。

## 曾考虑的替代方案

**只在 localStorage 保存上次位置。** 能在本机刷新恢复，但 URL 仍不能表达位置，不支持复制链接，且容易让不同标签页相互覆盖。因此采用每个标签页自己的 URL。

**使用 `/admin/widgets/<id>` 等路径路由。** 适合独立详情页面，但当前详情是筛选列表之上的弹窗，筛选和版本仍需要查询参数；额外还需处理静态资源入口回退。当前保留单入口查询参数，未来增加独立页面时再评估路径路由，并保留旧链接兼容。

**只保存状态和 Widget ID。** 改动较少，但刷新会丢失英文／原稿选择、源码展开与加载更多的范围，不能完整恢复现有浏览视图。一并覆盖这些可分享状态。

**直接把下一页 cursor 当作页面位置。** 现有 cursor 指向下一批起点，仅保存它无法恢复此前累加展示的列表。采用批数并重新遍历，代价是深列表恢复有更多请求。

## 后果

管理员可以刷新、分享位置和使用浏览器历史；URL 与历史中不包含审核文案、拒绝原因、源码内容或凭据。投稿 ID 与状态仍可能出现在浏览器历史和访问日志，数据访问继续要求管理鉴权。没有增加草稿持久化，确认整页离开后未提交文案会丢失；后续草稿能力可独立扩展现有提交接口。

恢复读取的是当前数据下的浏览范围，不是旧快照或相同像素位置；状态变化可能影响列表数量和顺序。深列表需要更多请求，可停止的分批恢复及独立详情加载限制等待影响。长期浏览数千条作品时，可以另行评估服务端定位或真正分页导航；不能把保存下一页游标当成完整累加列表的恢复。原生离页提示由浏览器控制，不能保证所有环境都展示或指定其文字。
