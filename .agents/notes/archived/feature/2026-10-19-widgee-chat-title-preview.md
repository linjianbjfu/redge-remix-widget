# Agent Note: Widgee 会话自动命名与内嵌 Widget 预览

Status: implemented
Archived: 2026-11-05

## 问题

默认“新对话”无法区分多个会话；生成结果只有名称与摘要，需要进入编辑器才能看到 UI。用户需要根据问题辨识会话，并在聊天中查看每次修改产生的 Widget。

## 决策

标题由服务端生成和持久化，iOS 消费摘要及有持久化序号的 `session_updated` 事件。第一条问题的截取提供即时兜底；待命名会话向当前模型暴露 `set_session_title`，成功结束时才发布候选标题。命名与 Widget 提交独立，因此普通讨论也能命名。标题来源区分临时、模型和用户指定，后续 Widget 修改不反复改名。失败、取消、过期 attempt 与事务回滚不发布标题。

命名复用当前生成会话，不创建另一个会话或独立命名任务，但工具调用后的模型续答仍会增加用量。SDK 一致的已知旧版本会话在继续或恢复生成时升级到当前提示词版本，历史读取不收费启动命名；未知版本与 SDK 错配仍被拒绝。字段、限额和兼容行为由 [Widgee 协议](../../../../docs/widgee-protocol.md)拥有。

聊天结果使用 `widget()` 与 WidgetNodeView 自动渲染，支持小、中、大尺寸。它展示桌面布局而非小应用的 `render()`。源码完整性校验在执行前完成；真实 API、独立草稿与点击配置由[聊天配置草稿与真实预览](../../proposed/feature/2026-10-20-widgee-chat-saved-configuration-preview.md)维护，部分取代本记录的设备示例隔离决策；离线采用校验仍使用 stub。预览只在卡片可见时启动，串行执行并保留有界缓存，离开会话后取消任务并拒绝迟到结果。具体生命周期由 [iOS 设计](../../../../ios/DESIGN.md#后端通信边界)维护。

自动预览不采用代码；用户通过结果卡片发起校验和添加，也可使用编辑器。更新保留已有 UUID 与 storage。预览失败在卡片中显示，可手动重试，不自动调用模型或上传设备数据。

[Chat 图片缓存](2026-11-04-chat-widget-image-cache.md)拥有卡片 PNG 展示、跨页面留存和会话删除清理；本记录的标题、版本和显式采用决策继续独立。

本记录接续[聊天生成决策](2026-10-19-widgee-widget-chat.md)，改变预览启动时机并扩展标题能力。该记录仍拥有服务端历史、版本发布及幂等机制；[原生移植记录](2026-10-19-widgee-ios-native-runtime.md)仍拥有运行时和真实设备能力边界。取代检查保留两篇活跃记录，无归档或删除。

## 曾考虑的替代方案

**只截取首条问题，或直接使用 Widget 名称。** 截取适合作为兜底，但长问题仍难辨识；Widget 名称不能覆盖普通讨论。选择模型独立提交主题标题。

**另起模型请求生成标题。** 可以独立重试，但增加任务、费用和取消竞争。当前会话已有问题上下文，短工具提交足够；命名质量证据表明不足时再考虑拆分。

**在聊天中运行真实小应用。** 能直接互动，但打开历史会触发真实权限和数据访问，且 `render()` 不能代表 Widget。静态 Widget 预览隔离私人设备数据，真实交互留在采用后的运行页和桌面。

## 验证

后端 129 项测试、pi SDK 9 项测试通过。新增用例覆盖标题格式、无产物命名、稳定标题、自定义名称、旧版本升级、SDK 错配、幂等重放、失败/取消/旧 attempt，以及标题与产物的事务回滚。

iPhone Air（iOS 27.0.1）通过 13 项单元/集成测试和 1 项真实模型 UI E2E：创建、退出恢复、AI 标题同步、聊天内三种尺寸预览、修改为绿色且目标改为 10、编辑采用、确认原计数保留并继续点击。测试同时覆盖原生 Widget 注册表与持久化、预览使用 stub storage、非法哈希拒绝、设备/远程图片隔离、缓存上限、渲染失败与修复后的预览，以及会话切换后的迟到渲染。异步生命周期测试使用显式 barrier，不依赖固定 sleep。系统通知中断导致的第一轮 UI 失败不计入通过；测试处理横幅并等待保存页面退出后，完整流程通过。

真实模型 gpt-6.1-sol 对同一个天气能力问题各运行一次：提示词变更前首轮输入 8,087 tokens，变更后 8,202（增加 115）；总输入从 8,087 增至 16,971，模型调用从 1 次增至 2 次。新会话得到“天气 Widget 可显示的信息”，没有生成代码。输入含缓存 tokens；这是命名成本和行为的小样本，不代表总体成功率。

TypeScript、SwiftLint strict、SDK 一致性及负例、iOS 移植门禁、文档链接、Notes 和 diff 检查通过。真机重跑命令由 [iOS README](../../../../ios/README.md#真机聊天生成测试)维护。本轮不重复验证主屏幕 App Intent 与长期 WidgetKit 调度，沿用已有验收边界。

## 后果

[中英文界面](2026-10-23-widgee-ui-localization.md)按请求语言展示未命名占位标题，保留本记录的 AI、自定义和问题截取标题语义。

[聊天联网预览](2026-10-20-widgee-chat-network-preview.md)保留联网与离线校验分离、缓存及取消的理由；当前设备数据与配置规则由聊天配置草稿提案拥有。

[底部导航与可视化资料库](2026-10-19-widgee-tabbed-chat-library-ux.md)拥有直接添加、持久化尺寸和本地缩略图决策；采用入口不要求进入编辑器。

[预览裁切与桌面一致性修复](../bug-fix/2026-10-19-widgee-widget-preview-parity.md)拥有共享宿主、实测尺寸与控件外观决策；聊天和编辑器复用桌面布局，App Intent 按原尺寸恢复处理器。

会话可通过内容辨识，历史结果可直接比较布局；标题和源码仍以服务器为准。采用前的预览不会读取已有计数，所以预览中的示例计数与实际采用后的持久化计数可以不同。

自动预览仍执行生成 JavaScript；现有运行时超时不能保证强制终止任意死循环，可见性、串行化及缓存限额不构成不可信代码沙箱。联网预览也不能证明私人设备权限或 WidgetKit 调度成功。

手动重命名、聊天内交互式试用和随主题变化反复命名不在本次范围。标题来源、不可变版本和独立预览组件保留后续扩展空间。
