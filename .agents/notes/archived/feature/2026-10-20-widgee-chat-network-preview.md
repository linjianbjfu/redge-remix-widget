# Agent Note: Widgee 聊天联网预览

Status: implemented
Archived: 2026-11-05

## 问题

“微软股票大组件”会话的聊天预览显示“暂无行情”，采用后正常显示价格。两处源码一致；聊天的 stub fetch 返回 HTTP 200 和 `{}`，脚本无法解析 Yahoo 行情并进入空状态。用户需要在聊天中看到真实网络数据形成的布局，并通过后续消息修改 Widget。

## 决策

联网与离线校验分开执行。[聊天配置草稿与真实预览](../../proposed/feature/2026-10-20-widgee-chat-saved-configuration-preview.md)部分取代这里的设备模拟和空存储决策，当前 Chat 入口为 ChatLivePreview，使用真实 Widget 注册表和独立草稿副本。下述 ChatNetworkPreview 能力集合保留在代码及对照测试中，不是当前卡片入口。采用校验、源码编辑器的校验预览、资料库缺少快照时的 fallback 继续调用离线 `ChatPreviewStore.render`；更改聊天不能使这些入口隐式联网。

### 保留的 ChatNetworkPreview 实现

ChatNetworkPreview 支持 `fetch.request`、全局 fetch、`fetch.image` 和 Image 的 HTTP(S) 地址，保留请求方法、正文、显式 headers 和响应状态。每次运行使用独立临时 URLSession，不携带共享 Cookie、系统凭据或后端服务令牌。网络图片缩放后直接转为内联 PNG，不经过共享 ImageStore；设备文件和共享图片 ID 不能解析。预览任务拥有完整图片下载过程，SwiftUI 展示不继续发请求。

storage 使用本次运行的临时目录，允许脚本读回刚写入的缓存，退出后清理；不同预览不共享目录，也不读取或写入已采用 Widget 的配置、计数与快照。私人设备能力仍使用示例模块，预览保持静态，不触发控件操作。说明标记“联网预览 · 设备数据为示例”，区分网络能力与设备数据真实性。

[地图位图](2026-10-20-widgee-map-snapshot-api.md)通过独立 PreviewMaps 适配器扩展真实地图截图，不开放 maps 的其他真实方法，不改变私人定位与配置的隔离。地图请求使用 MapKit 的网络实现，返回内联 PNG，和 HTTP 下载的图片一样无需共享图片 ID。

有限时长的预览不开放文件上传、文件下载和长连接 API；调用返回明确的不支持错误，正式运行的 API 不变。执行总预算包含网络及图片处理，取消和超时会关闭网络会话。单响应、累计字节数与请求次数都有上限，响应未声明 Content-Length 时同样计数。这些限额属于 ChatNetworkPreview 及其 PreviewNetwork 下载器，不是当前真实注册表中所有 API 的统一限额；当前执行范围见 [iOS 设计](../../../../ios/DESIGN.md#后端通信边界)。

### 当前继续使用的预览规则

[Chat 图片缓存](2026-11-04-chat-widget-image-cache.md)拥有卡片呈现和留存，真实 API 和草稿来源保持独立。

内存和磁盘图片缓存避免滚动、回访和重启重复联网。卡片始终提供刷新入口，重新取数并替换成功图片；脚本自行捕获网络错误形成的空状态也能刷新。同版本同尺寸刷新保留旧画面，宿主失败显示错误；不同版本或尺寸不借用旧画面。离开会话或进入后台取消生成并释放内存，磁盘图片保留。串行执行、代际检查和删除屏障防止迟到结果更新卡片或恢复已删除图片。

网络失败不自动调用模型；用户继续在原会话发送修改要求，服务端保存后续版本。预览不自动上传响应、配置或业务数据；脚本自身的网络请求不受此保证约束。

本记录部分替代[会话命名与内嵌预览](2026-10-19-widgee-chat-title-preview.md)的全 stub 与外部图片限制。该记录的标题、可见性和版本机制仍有效；[资料库设计](2026-10-19-widgee-tabbed-chat-library-ux.md)的快照与采用隔离、[原生运行时](2026-10-19-widgee-ios-native-runtime.md)的设备权限边界、[聊天生成](2026-10-19-widgee-widget-chat.md)的服务端历史与发布规则继续有效。取代检查保留这些活跃记录，无归档或删除。

## 曾考虑的替代方案

**直接使用完整真实 Widget 注册表。** 网络行为自然一致，但打开聊天历史也可能读取联系人、健康、已有文件或触发权限。联网能力与私人设备数据分开开放，满足采用前检查 UI 的需求。

**只将共用渲染函数里的 stub fetch 换成真实 FetchModule。** 改动小，但同一入口还用于采用校验、编辑器和缩略图 fallback；真实 FetchModule 的共享会话、上传和共享图片处理也超出聊天预览需要。选择独立入口和显式能力集合。

**继续使用示例行情。** 可离线展示布局，但无法验证生成脚本的请求、解析和真实数据排版，不能解决用户看到空状态后无法判断 UI 的问题。

## 验证

连接的 iPhone Air（iOS 27.0.1）通过 19 项单元与集成测试：ChatNetworkPreviewTests 9 项、ChatPreviewTests 6 项、ChatScrollLayoutTests 4 项。覆盖真实 HTTP 与全局 fetch、参数与响应、远程图片、HTTP 错误与连接中断、刷新缓存、临时 storage、Keychain 示例隔离、离线校验不联网、非法哈希拒绝、超时取消、串行执行与迟到结果，以及吐字期间的位置稳定。资源负例覆盖第 17 次请求、超过 12 MiB 总量、超过 4 MiB 的 Content-Length 和未声明长度的响应。HTTP fixture 绑定随机端口；取消测试等待服务端收到请求后才取消。

两项真机 UI E2E 通过：原“微软股票大组件”会话无需重新采用即显示 Yahoo 的 `$533.52`、涨跌与走势图，大中小尺寸及刷新均可用；独立测试账号通过两轮真实模型生成蓝色股票 Widget，再修改成深绿色并增加“实时行情”文字，两版均在采用前显示真实价格。截图已人工检查。测试未采用 QA Widget，结束时恢复原服务账号，服务地址使用当前 Wi-Fi 的 LAN IP。

真机构建、SwiftLint strict、`npm run verify-ios -- --static`（包含 7 项静态门禁与负例）、文档、Notes、shell 语法与 diff 检查通过。重跑参数由 [iOS README](../../../../ios/README.md#真机聊天生成测试)维护。初轮测试中的 stub 返回值和错误处理断言修正后重跑通过；失败轮次不计入上述结果。

## 后果

聊天可用真实网络数据检查布局并继续修改；打开可见历史结果也会访问脚本指定的远端地址，可能产生请求费用或远端副作用。缓存避免滚动重放，用户刷新则重新执行请求。运行时不是任意不可信代码的安全沙箱。

行情源可能限流、不可达或超出预算，两次请求之间价格也可能变化。联网预览保证执行真实请求，不保证外部服务始终成功或聊天与桌面在不同时间数值相同。脚本捕获请求错误后的展示由脚本决定。

ChatNetworkPreview 的测试证据不证明真实私人数据、配置表单或桌面调度有效。当前 Chat 的真实 API、持久草稿和采用复制由[聊天配置草稿与真实预览](../../proposed/feature/2026-10-20-widgee-chat-saved-configuration-preview.md)拥有；其地图配置真机验证已通过，完整采用更新 UI 验收及 HealthKit 真机读取仍有待完成。
