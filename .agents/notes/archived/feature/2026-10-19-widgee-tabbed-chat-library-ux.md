# Agent Note: Widgee 底部导航与可视化 Widget 资料库

Status: implemented
Archived: 2026-11-05

## 问题

资料库作为首页、聊天与设置作为 sheet，使创建 Widget 的路径分散。聊天结果必须进入源码编辑器才能采用，预览尺寸无法保存，只有名称的资料库也无法辨识 Widget 布局。用户需要从 Chat 创建、选择尺寸、直接添加，再从资料库看到实际外观。

## 决策

自定义底部导航的实例统一与 Chat 抖动修复见[稳定底部导航](../bug-fix/2026-10-30-stable-bottom-navigation.md)；本记录继续拥有页面职责和资料库行为。

应用使用 TabView 管理 Chat、Widget 广场、我的 Widget、设置四个页面，默认打开 Chat；根容器提供统一自定义底部导航。广场展示审核通过的 Widget，其系统背景、分类列表与截图卡片由[分类浏览](2026-10-25-gallery-category-sections.md)拥有。键盘、安全区与无障碍行为由页面和根导航协同处理，冰蓝淡紫渐变和圆角表面只作用于应用外壳，不覆盖脚本样式。根容器持有稳定聊天模型与独立运行请求，设置保存后使旧模型失效并创建新模型。

历史在左侧抽屉展开，服务器继续拥有会话、正式消息和代码版本。新对话先保留本地草稿，首次发送才创建会话。切换 Tab 或进入后台只断开订阅，恢复时继续同一 turn；配置与草稿按服务地址和用户隔离。连接使用[长生成 SSE 心跳与有界恢复](../bug-fix/2026-10-21-widgee-sse-idle-recovery.md)，建连与读流共用预算；保持同一 turnId 和持久化游标，耗尽预算后保留手动恢复入口。

采用由用户在结果卡片上发起，完整性、生命周期与所选 Widget 尺寸校验通过后才保存。一个云端会话对应一份稳定本地 UUID，更新保留 storage，重复添加同版本同尺寸不写入。校验期间本地发生变化时拒绝覆盖，已有本地源码编辑需要确认替换。编辑器、导入、示例及没有 widget() 的应用入口仍保留。已采用结果可直接打开相同本地身份的运行页完成配置；字段读取修复与天气服务验收见[天气采用与配置](../../proposed/bug-fix/2026-10-19-widgee-weather-adoption-configuration.md)。

尺寸是本地记录的必填偏好，不是独立副本身份，也不控制主屏幕实例的实际 family。项目未上线且用户明确允许删除旧资料，资料库与快照直接使用新格式，不提供迁移、字段回填或兼容解码。验收设备的一次性清理包括本地脚本、storage、索引和派生缓存，保留服务器会话与连接凭据；清理不是应用启动行为，损坏文件不能触发自动重置。

资料库使用共享 Widget 渲染器生成本地图片。优先选择源码哈希、family 与实际宽高全部匹配的真实快照，否则执行隔离 stub。Widget 卡片仅显示缩略图。仅浏览资料库不能调用真实桥接或申请权限，也不能因展示真实快照图片重新联网。图片键覆盖源码、尺寸、外观、字号、倍率、渲染器版本、快照内容和保存时间；原子记录绑定图片与来源时间，取消、删除和更新后的迟到结果不得写回。缓存有界、可重建、排除备份且不自动上传，具体字段及限额由 [iOS 设计](../../../../ios/DESIGN.md#资料库缩略图)维护。

[会话命名与预览](2026-10-19-widgee-chat-title-preview.md)继续拥有服务端标题，[联网预览](2026-10-20-widgee-chat-network-preview.md)拥有聊天网络和设备数据隔离，本记录拥有直接添加入口；[桌面一致性](../bug-fix/2026-10-19-widgee-widget-preview-parity.md)继续拥有共享布局，本记录扩展尺寸持久化与快照出处。[运行身份](../bug-fix/2026-10-19-widgee-run-presentation-identity.md)和[原生运行时](2026-10-19-widgee-ios-native-runtime.md)的生命周期、权限及存储约束继续有效。这些记录只被部分延伸，均保持活跃，没有归档或删除。

## 曾考虑的替代方案

**资料库全部实时运行 Widget。** 能尝试读取新数据，但滚动会触发脚本、权限及网络，且增加主线程、内存与电量成本。采用快照图片，用户打开运行页时才使用真实应用能力。

**资料库只显示添加时截图。** 实现简单，但源码更新、切换尺寸和真实运行后会长期展示旧内容。缓存必须带版本、尺寸与内容出处，并可重新生成。

**同一会话按每个尺寸保存独立副本。** 能同时展示三个版本，但需要决定计数等 storage 是否共享、云端更新覆盖哪些副本以及桌面选择如何区分。当前保留一份脚本和稳定 storage，以尺寸偏好满足展示要求；如需要多份独立 Widget，再引入显式副本身份，不能仅用名称区分。

**保持编辑器作为必经采用步骤。** 校验清晰，但普通用户被迫接触源码。将相同校验放在“添加”操作中，保留可选编辑器。

**迁移旧资料库并兼容旧快照。** 项目尚未上线，用户允许直接删除旧数据，因此不承担迁移与兼容分支的维护成本。通过一次性清理开发数据开始使用新格式。


## 验证

iPhone Air（iOS 27.0.1）通过 30 项单元与集成测试，以及真实后端和模型的聊天 UI E2E：冷启动恢复生成、AI 标题与历史、三种尺寸直接添加和更新、重复采用不增加副本、尺寸持久化、更新后保留计数、历史抽屉与广场占位。主屏幕 App Intent 测试点击后计数从 3 增至 4，回到资料库显示对应真实快照；导航回归逐一打开前三张卡片，切换设置身份并恢复原身份，验证历史隔离与恢复。

真机截图核对聊天三种尺寸、历史抽屉、资料库、主屏幕，以及 Debug 外观覆盖下的深色与最大辅助字号。外壳随字号调整为单列；生成喝水脚本在最大辅助字号下的文字和按钮仍会截断。VoiceOver 焦点、减少透明度与减少动态效果有实现，但本轮没有完整的人工辅助功能走查，不据此宣称所有辅助模式验收完成。

新增单元用例覆盖尺寸编解码和非法格式、添加幂等与失败保护、并发编辑保护、缓存键、磁盘淘汰与损坏重建、删除后迟到结果、离线图片重用且不执行 JS、本地图片来源限制，以及同状态共享渲染器像素一致性。异步竞争用显式 barrier 控制。Runtime 的 6 项 WidgetRunner 测试通过；临时移除源码与 context 匹配检查时，出处回归测试按预期拒绝，恢复实现后通过。

SwiftLint strict 覆盖全部变更 Swift 文件；iOS 契约及负例、文档链接、Agent Notes 和 diff 检查通过。运行入口和设备前置条件由 [iOS README](../../../../ios/README.md#真机聊天生成测试)维护。连接丢失和测试文本选择问题的失败轮次不计为通过。

## 后果

[会话排序与后置历史列表](../bug-fix/2026-10-22-widgee-session-update-order.md)规定按更新时间排序、聊天页右移露出后方列表及展开触觉反馈。

[进度条缩略图一致性](../bug-fix/2026-10-20-widgee-progress-thumbnail.md)记录系统进度条不能被 ImageRenderer 绘制的限制，以及共享图形样式和图片缓存版本失效的修复。

配置保存后的缩略图和桌面刷新、运行页的所选尺寸预览由[配置与 Widget 刷新](../bug-fix/2026-10-19-widgee-configuration-widget-refresh.md)维护。

详情页尺寸选择延伸同一份 preferredFamily，成功渲染后才保存，不创建新副本；纯 Widget 的可操作详情与配置表单保留规则见[详情页尺寸与可选配置页](2026-10-19-widgee-widget-detail-controls.md)。

资料库可辨识尺寸和布局，同时避免滚动列表反复运行真实模块。代价是截图只能代表最近一次匹配快照，不能承诺桌面与资料库实时一致。真实快照可能包含设备数据，缓存只保存在本机并随脚本删除清理；系统着色、字体和尺寸记录时效仍可能影响外观。

旧本地数据不迁移，已有桌面实例可能需要重新选择脚本。新的数据在冷启动和后续更新中正常保留；新格式缺失尺寸或出处时直接拒绝。若以后支持同一会话的多份独立 Widget，必须引入明确副本身份与 storage 语义，不能仅按名称或尺寸区分。

stub 仍执行 JavaScript，现有运行时不能保证强制中断任意死循环。串行生成、取消与缓存限额不是安全沙箱，校验成功也不保证所有权限、硬件或脚本布局正确。预览或采用失败保留已有版本，不自动请求模型修复。

广场服务、发布分享、自动放置主屏幕 Widget、多尺寸独立副本与新后端协议不在本次范围。稳定 Widget 身份、尺寸枚举和版本化缓存允许后续扩展；所有系统 API 成功路径、长期 WidgetKit 调度和锁屏尺寸仍沿用原生移植记录中的验证限制。

[Widget 广场分享与审核](2026-10-22-widget-gallery-sharing-moderation.md)拥有共享目录和显式上传截图的入口；本记录继续拥有本地资料库与自动缓存行为。
