# Agent Note: Widget 广场分享、审核与本地采用

Status: implemented
Archived: 2026-11-05

## 问题

个人资料库和聊天产物不能让其他用户发现与采用 Widget。共享目录需要跨用户查询，投稿需要审核，作者的运行配置不能随代码复制到其他用户设备。

## 决策

广场使用 Worker 直接访问 D1、私有原始产物桶与独立公开发布桶，聊天仍由用户 DO 承载。[客户端协议](../../../../docs/widgee-protocol.md#widget-广场)拥有字段、上限、接口与错误码；[开发指南](../../../../docs/development.md#widget-广场与-admin)拥有 migration、资源绑定、Admin 构建和部署步骤。

### 不可变产物与状态同步

D1 的 shared_widgets 保存投稿元数据、推荐 small/medium/large size、审核状态、完整性信息及 R2 前缀，不保存图片像素宽高或产物正文。作者自提交起不能修改，改版和驳回后重投均需新投稿。[审核文案编辑](2026-10-22-admin-gallery-browsing-editing.md)允许管理员在待审核时随审核结果修正标题与简介，产物保持不可变。审核是一次性决定，相同结果及显式文案的重试幂等，不同结果或文案冲突。

[单表状态同步](../architecture/2026-10-22-gallery-single-table-sync.md)拥有 status 和 update_at 协议，替代独立发布表及发布 ID 游标。批准、拒绝和删除均更新同步版本，因此先提交、晚批准的作品仍会出现在新一页；客户端不能把提交顺序当作可见顺序。目录与游标原子保存；不能任意淘汰仍有效的旧目录摘要后保留高位游标，否则无法恢复被丢弃的条目。目录损坏从 0 重建，图片单独淘汰。

[Admin 删除](2026-10-22-admin-gallery-deletion.md)拥有删除确认、不可恢复终态与产物清理。已经采用的本地副本独立保留。

### 固定产物路径与失败恢复

原始产物在私有 R2 的 shared-widgets/<sharedWidgetId>/ 下固定保存 thumbnail.png 与 widget.js。哈希用于重试一致性与下载校验。首次条件写入的图片元数据绑定完整请求摘要，防止并发请求拼接不同内容；已有对象只允许相同内容重试。两份原始产物写入后创建 D1 pending_translation 记录；语言派生产物的版本路径由[双语产物](../../implemented/feature/2026-10-23-shared-widget-localization.md)拥有。

客户端持久化提交键和完整内容，不确定失败重试同一份内容。提交键含固定创建时间和 UUID；上传期限不能续期。服务端限制未来时钟偏差，D1 最终插入再次检查期限，成功投稿的相同重试仍返回已有状态。固定期限防止清理后重新启用旧键：即使清理任务重叠或旧写入迟到，也不会删除仍有资格提交的新上传。客户端收到 upload_expired 后保留内容、换新键重投。

R2 与 D1 没有跨服务事务，部分写入或 D1 失败可能留下孤儿对象。定时清理在上传期限后额外等待宽限期，检查对象年龄、期限和 D1 引用，不删除 status 非 deleted 的已提交产物。清理可重复运行；不能在上传请求失败时直接删除同路径对象，因为并发重试可能已提交成功。

### 分享、浏览与采用

详情页分享入口受[实验功能编译开关](2026-10-23-widgee-experimental-features.md)控制，默认关闭。开启后自动使用已有名称和简介，无需填写表单或额外调用模型。名称为空时使用默认名，超长文字按服务端相同的 Unicode 码点上限截断分享副本，不改写本地内容。分享冻结当前成功渲染的视图树、源码和 size，仅生成一张 PNG；预览未完成或尺寸不匹配时不能提交。确认页展示实际内容。待确认的失败投稿持久化后，后续重试继续展示该副本。

只上传截图与源码，不复制 storage、聊天、Keychain 或个人文件。截图仍可能含个人信息，源码也可能硬编码秘密；预览和人工审核不能保证识别所有泄露。依赖作者私有文件的作品需要先改为可自行配置或获取资源的模板，首版没有通用文件包。

广场列表和详情只展示截图，图片保持原比例。[分类浏览](2026-10-25-gallery-category-sections.md)拥有分类首页、查看全部和尺寸角标。只有点击“添加到我的 Widget”才下载代码，验证字节数、哈希、SDK、生命周期和推荐尺寸，然后保存独立本地 UUID、空 storage 与 preferredFamily。重复采用识别来源而不覆盖本地编辑，不冒用 cloudSessionID。下载或校验失败不保存半成品。采用后的运行、编辑、配置及桌面使用复用资料库行为，其他用户与作者的原作品不受影响。

### 审核与读取权限

Admin 是同一 Worker 托管的 /admin/ 静态网站，通过独立 ADMIN_TOKEN 登录后使用内存访问令牌和 HttpOnly 刷新 Cookie 恢复会话。全部管理 API 和产物读取验证访问令牌，并兼容原始管理口令；静态页本身不含投稿数据。页面按文本显示用户内容和源码，不执行投稿代码，也不模拟 iOS 运行器。

[Admin 多设备登录](2026-10-23-admin-session-login.md)拥有短期访问令牌、可撤销刷新会话与多设备退出规则。

公共完整摘要要求投稿已批准且双语公开引用齐全。列表同步中的其他状态仅包含 ID、状态与更新时间。私有原始桶不提供公共 URL；批准后的独立公开副本及撤回窗口由[双语产物](../../implemented/feature/2026-10-23-shared-widget-localization.md)拥有。App API 的无 token 接入由[Keychain 客户端身份](../../implemented/feature/2026-10-26-client-keychain-identity.md)拥有，提交者引用只作来源记录，不能证明真实身份；后续账号体系集中替换鉴权入口，不把密码或角色固化到业务表。

### 与现有决策的关系

[资料库与 Tab 设计](2026-10-19-widgee-tabbed-chat-library-ux.md)继续拥有本地采用与自动缓存，显式分享由本记录拥有；自动缓存不会自动上传。[详情页设计](2026-10-19-widgee-widget-detail-controls.md)继续拥有尺寸与运行行为。[工作区文件系统](../architecture/2026-09-28-server-workspace-filesystem.md)的 DO 决策针对用户会话工作区，广场不迁移该工作区。三篇均保留活跃，无完全取代、归档或删除。

相关决策：[Shared Widget 中英文内容与缩略图](../../implemented/feature/2026-10-23-shared-widget-localization.md)拥有语言生产、公开发布及按语言读取的扩展，完整客户端和设备验收状态由该记录维护。

## 曾考虑的替代方案


**在用户 DO 中保存分享，再聚合所有用户。** 需要跨用户扫描和额外全局目录，用户已明确要求 D1，共享查询也适合关系索引，因此不采用。独立全局 DO 虽能集中数据，但没有必要为列表引入单个对象的协调职责。

**D1 直接保存 PNG 和代码。** 可以减少两个存储系统之间的一致性处理，但会把目录查询与较大产物绑在一起；采用用户提出的 R2 产物方案，接受清理孤儿对象的成本。

**在 R2 目录中增加 contentHash。** 每份投稿的截图和代码不可修改，改版会创建新的 sharedWidgetId，因此每个分享 ID 下只需一份固定产物。直接以分享 ID 定位目录，哈希仅用于校验。

**使用 gallery_changes 保存更新与删除。** 投稿产物固定、改版创建新条目；单表更新时间足以传递当前状态，不保留独立变更日志。代价是不提供每次审核变化的完整历史。

**提交时分配公共 id 并跳过未审核条目。** 乱序批准会漏项。提交顺序严格阻塞虽能避免遗漏，但长期待审会阻塞后续所有内容。因此同步版本必须在批准时推进，不能仅在首次提交时分配。

**单表保存待审提交和可空的发布 id。** 可以分离提交与发布身份，但批准时需要另行分配序号，也不能表达删除。当前单表同步使用每次状态转换都会推进的 update_at，不保留发布 ID。

**打开详情就下载代码。** 用户明确选择只有添加时才下载，截图详情无需代码，采用延迟下载降低浏览成本并避免浏览触发执行。

**上传完整个人运行目录。** 能复制更多作者环境，但混入个人配置和设备资源，用户明确要求只分享截图和代码。使用者重新配置，暂不引入通用资源包。

**R2 公共 URL 长期直出。** 读取便宜，但只过滤列表无法阻止直接访问待审或已下架对象。首版由 Worker 校验状态后提供产物；使用 CDN 时还需另行明确撤回时效。

**Admin 完全无认证或立即建设账号体系。** 前者只适合封闭环境，后者与即将重设计的用户系统重复。用户已选择独立管理口令。

## 验证

[后端测试](../../../../backend/src/gallery/gallery.test.ts)在真实 Workers/D1/R2 测试环境覆盖输入限制、未审核资源权限、乱序批准与分页、并发投稿和审核、事务回滚、部分上传/D1 失败重试、期限及孤儿清理。相关回归结果由[单表同步记录](../architecture/2026-10-22-gallery-single-table-sync.md)维护。

[iOS 测试](../../../../ios/WidgeeTests/GalleryTests.swift)覆盖目录/游标原子记录、损坏重建、待提交副本持久化、重复采用、本地编辑保护、三种推荐尺寸及离线/哈希/SDK/生命周期失败。GalleryTests、WidgetDetailTests、LibraryUXTests 共 17 项真机测试通过；SwiftLint、新版签名构建、TypeScript、Admin 构建和 iOS 静态门禁通过。

[真机 UI 验收](../../../../ios/WidgeeUITests/GalleryE2ETests.swift)使用真实本地 Worker 和模型生成饮水 Widget：依次打开小、大、中分享预览，提交当前中尺寸截图；浏览器 Admin 查看真实截图与源码后批准；另一用户在广场添加，作者截图为 2 杯，采用后初始为 0 杯，可独立增加到 1 杯，冷启动仍识别已有副本。浏览网络只有目录和图片，添加才请求代码。Admin 截图序列 GIF 与真机 xcresult 保存在忽略的 .playwright-mcp/gallery-live/，演示当前未提交工作树，没有对应 PR 或已发布提交。

## 后果

D1 目录与 R2 产物分离，浏览无需下载代码，也不需要聚合用户 DO；代价是上传期限、跨存储失败恢复、清理及额外部署绑定。客户端时钟领先过多会拒绝新投稿，需要修正设备时间。新设备必须从 0 分页建立目录，首版没有直接跳到最新一页的协议。

截图与代码是否一致、源码是否包含隐私、运行行为是否符合展示，不能仅靠静态解析或人工看图保证。现有运行时不是任意不可信代码的安全沙箱；需要更强隔离时必须单独设计。Admin 审核不等于运行正确性验证。

云端资源、生产部署与同源公开资源由[Keychain 客户端身份](../../implemented/feature/2026-10-26-client-keychain-identity.md)拥有；全零 preview_database_id 只用于保留本地开发库。真实端到端验证使用本地服务与物理 iPhone；未新增 WidgetKit 长期调度或所有系统 API 的实机覆盖，采用后的这些行为继续复用现有路径。

完整账号体系、投稿状态中心、作者主页、搜索分类、点赞排名、订阅更新、通用资源包不在首版。稳定来源身份、不可变产物和独立鉴权入口保留后续扩展空间。
