# Agent Note: Admin 缩略图浏览与审核文案编辑

Status: implemented
Archived: 2026-11-05

## 问题

审核者需要在发布前修正标题与简介。上传重试和数据备份依赖原始请求摘要；如果直接以审核后的文案重算摘要，会破坏上传幂等性和备份兼容性。浏览大量投稿也需要以截图为入口，而不是逐项打开文字列表。

## 决策

Admin 默认显示已通过的缩略图网格，点击卡片打开详情。截图按可见区域加载且最多四个并发请求，源码仅在展开时请求；切换列表、关闭详情和退出会取消对应请求并释放图片资源。详情通过语言选择展示译文或原稿的截图、文案与源码，切换保留未保存的双语文案。桌面并列展示截图与详情，窄屏纵向排列；关闭未保存的修改需要确认。交互与操作说明见 [Admin README](../../../../admin/README.md)。

管理员仅在 pending 审核转换时按语言编辑 name 和 summary。文案、分类、审核信息、状态与严格递增 update_at 在同一条件事务中写入；相同结果及文案重试成功，不同文案或结果冲突。审核后的文案只读，修改产物仍需新投稿。字段上限、可选字段及错误码由[协议](../../../../docs/widgee-protocol.md#widget-广场)维护。

request_hash 始终代表原始上传请求，截图、代码、尺寸、投稿身份和 R2 元数据不变。这样作者上传重试仍能识别原提交，不要求数据库保存第二套原始文案，父记录保留原始文案，语言记录保存审核文案。

导出 v6 明确分开原始请求摘要与审核后的展示文案。它保留字段与产物完整性校验，不用现有标题与简介重算 request_hash。v1/v2/v3 继续按原格式校验原始摘要；同 ID 合并保留目标文案、状态及游标，原始身份或产物不同仍拒绝。运维契约由[导入导出](../process/2026-10-22-gallery-data-transfer.md)与[开发指南](../../../../docs/development.md#widget-广场与-admin)维护。

本记录部分调整[分享与审核](2026-10-22-widget-gallery-sharing-moderation.md)的文案不可变约束与导入导出的重复判断。[单表同步](../architecture/2026-10-22-gallery-single-table-sync.md)的原子时间分配继续适用；三篇保留活跃，没有完全取代或归档。

相关决策：[Shared Widget 中英文内容与缩略图](../../implemented/feature/2026-10-23-shared-widget-localization.md)扩展共享内容的语言生产与读取；本地实现支持双语审核和发布进度，云端验收仍待完成。

[Admin URL 导航与刷新恢复](2026-10-24-admin-url-navigation.md)将筛选、详情和查看版本写入 URL，并拥有浏览器历史导航的未保存保护。

## 曾考虑的替代方案

**允许已发布文案随时编辑。** 当前需求是审核时编辑，审核完成后保持内容稳定。发布后编辑需要独立扩展，并通过 update_at 通知客户端。

**直接重算 request_hash。** 会让原始上传重试与 R2 元数据发生冲突，因此保留原始摘要，将审核文案与上传身份分离。

**增加原始标题和简介字段。** 能重算原始摘要，但需要 schema 迁移和重复数据。幂等比较只依赖保存的摘要，不需要恢复原文，因此不增加字段。

## 验证

`npm test -- src/gallery/gallery.test.ts` 的 19 项测试通过，覆盖文案校验、Unicode 上限、公共详情与增量列表、原始上传重试、审核幂等、并发胜者完整性和 D1 失败回滚。`npm run test:gallery-data --workspace @webclip/backend` 的 10 项测试通过，覆盖编辑后文案往返、重复导入保留目标文案、旧格式摘要拒绝、非法 v4 字段及既有冲突与失败恢复。

Admin 构建和 TypeScript 检查通过。Chrome 在隔离本地 Worker 上验证默认已通过、分页、批准和拒绝时保存文案、空标题拒绝、空列表、未保存修改提示、Escape 与焦点返回、按需源码、缺失产物提示及恢复重试、删除确认取消和退出。桌面及 390 像素窄屏均检查布局。截图保存在忽略目录 `.playwright-mcp/admin-review-rgit0c2z/`。

浏览器数据是既有模型产物的独立存储副本，加上用于分页和审核的 24 份测试记录；本次没有调用模型，没有修改默认开发库投稿，没有执行生产导入或部署。客户端接口字段未改变，本次未重跑 iOS 真机测试。

## 后果

审核者能够修正文案，发布内容仍只经历一次审核，上传身份和产物不受影响。代价是备份无法使用原始请求摘要验证审核后的文字；备份需可信保管，图片和代码仍独立校验字节数与哈希。旧版本脚本不能读取 v6，操作备份需使用当前脚本。

[分类审核](2026-10-25-shared-widget-categories.md)允许待审核作品独立保存分类，批准时必须已有或同时提交分类；分类与审核使用版本检查防止并发覆盖。文案不单独保存草稿，审核完成后不能直接修改。语言记录只保留当前审核文案，不保留编辑历史；父记录保留原始投稿文案；若需要审计历史，应另行设计记录机制。
